# Estimando Parâmetros em Modelos de Transmissão da Dengue com Monte-Carlo
Esse repositório, considerado material complemtentar do artigo escrito, guarda os códigos utilizados para a estimar parâmetros desconhecidos em um modelo SIR de transmissão da dengue no Rio de Janeiro, RJ, Brasil. 
Nele podemos encontrar os códigos da Cadeia de Markov via Monte-Carlo com inferência Bayesiana, arquivos `.md` para explicação de conceitos relevantes (talvez) e outros documentos que foram úteis no desenvolvimento do projeto.
