# Estimando-Par-metros-em-Modelos-de-Transmiss-o-da-Dengue-com-Monte-Carlo
Esse repositório guarda os códigos utilizados para a estimar parâmetros desconhecidos em um modelo SIR de transmissão da dengue no Rio de Janeiro, RJ, Brasil. Esse repositório é categorizado como material complementar do artigo de referência.
